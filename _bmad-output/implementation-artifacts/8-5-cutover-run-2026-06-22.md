     newest-first; the in-memory fixture seeds (`review_fixture_1_*`) are **absent**
     (clean swap).
   - Anon proof (anon key, outside the app): `select` on `public.reviews` →
     **succeeds**; `select` on `public.feedback` → **denied/empty**; `insert` into
     either as anon → **denied** (only service_role may insert).
b. **Engine spot-check (the 8.3 deferred check).** A known shadowed downtown spot
   reads shadowed with the 3.0.5 coverage caps applied (not falsely "sunny",
   confidence capped below the high band for unknown coverage).
c. **Live venue-data integrity (AC#4a / Task 6.1).** Confirm no duplicate `id` and
   no duplicate `slug` rows in `public.venues` (the runtime `validateVenueUniqueness`
   now keys on id + slug, matching the DB unique keys; coordinates are intentionally
   not a uniqueness key, so co-located venues are fine):
   ```sql
   select id, count(*) from public.venues group by id having count(*) > 1;
   select slug, count(*) from public.venues group by slug having count(*) > 1;
   -- both expect zero rows
   ```
