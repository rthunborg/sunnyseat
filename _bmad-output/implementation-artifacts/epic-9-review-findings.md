### Review Findings

- [x] [Review][Decision][Med] Venue-detail route AND feedback POST swept into the read-route rate-limit bucket — `proxy.ts` branches purely on `pathname.startsWith('/api/venues')` with no method gate, and `venueRateLimitMiddleware` applies the 120/60s per-IP token bucket to ALL matched requests. Confirmed `POST /api/venues/[slug]/feedback` exists and now shares one bucket with GET reads: heavy browsing can 429 a feedback submission (and vice-versa) — a net-new cross-route behaviour Story 9.3 AC3 scoped only to the "venue READ routes". Recommended: fix: gate `venueRateLimitMiddleware` to `request.method === 'GET'` (or exclude the `/feedback` subpath) so mutations keep their own quota, matching 9.3's own documented "READ routes" scope. [`nextjs-app/lib/utils/venue-rate-limit-middleware.ts:17`, `nextjs-app/proxy.ts:29`]
- [x] [Review][Decision][Med] DesktopNavBar active tag can orphan with no chip to clear it — `allTags` is derived from `collectTags(venueQuery.data?.venues)`; when the venue set changes (new location/time) and an active tag no longer appears in the union, its chip stops rendering (`allTags.length` gate) while the tag stays active in `TagFilterContext`, silently filtering the list + pins to empty with NO visible affordance to un-toggle it. Directly the "dead/confusing control" class Epic 9 Spine 3 set out to kill. Recommended: fix: on `venueQuery.data` change, prune `activeTags` to the intersection with the new `allTags` union (toggle-off tags no longer present) so a stale filter can never strand the list. [`nextjs-app/components/custom/layout/DesktopNavBar.tsx:57`]
- [x] [Review][Decision][Med] Honest-distance "≈ från centrum" annotation is not applied to the Favoriter list or the venue-detail "Avstånd" card — `MapView` threads `locationIsApproximate`/`distanceIsApproximate` into the two `VenueList` and two `VenueQuickInfo` sites but NOT into `FavouritesList` or the two `VenueDetailOverlay` sites, so on the Gothenburg-centrum fallback those surfaces still show an unqualified distance that implies a real personal fix — the exact dishonesty Story 9.5 AC3 targets, on surfaces neither 9.5 nor 9.9 named. Recommended: fix: thread `locationIsApproximate` through `FavouritesList` → its inner `VenueList`, and thread `distanceIsApproximate` to `VenueDetailContent`'s Avstånd card, mirroring the existing `VenueList`/`VenueQuickInfo` wiring. [`nextjs-app/components/custom/map/MapView.tsx:937`, `nextjs-app/components/custom/favourites/FavouritesList.tsx`, `nextjs-app/components/custom/venue/VenueDetailOverlay.tsx:1014`]
