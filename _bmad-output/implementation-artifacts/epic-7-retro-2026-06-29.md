## 2. What Went Well

1. **Front-loaded maintainer decisions.** Every story opened with an `AskUserQuestion` for the genuinely ambiguous calls (7.1 privacy page + hero + desktop entry; 7.2 bespoke 404 navbar; 7.3 Serwist variant + placeholder icons + AC5 reconciliation). No blocking ambiguity was discovered mid-build.
2. **The defer queue closed the loop end-to-end.** 7.3 pulled in five items deferred from Stories 1.3/1.5/1.6/3.4 reviews and cleared every one — the "queue-not-archive" convention proved itself, not just as bookkeeping.
3. **Reusable primitives, built once and properly.** The `useInView` count-up (7.1) and the `useOnlineStatus` hook (7.3).
4. **REBASELINE-LOG discipline held under churn.** Three stories each touched the shared visual-reference set; every addition/rebaseline was logged in the same change — and 7.2 even *caught* that the active `not-found` refs were unlogged legacy diverging from the ACs.
5. **Clean, fast reviews.** Three consecutive Round-1-clean reviews with one small defensive patch each and zero HIGH/MEDIUM survivors — the adversarial 3-layer review + code-verified triage is finding the real issues without thrash.

## 3. Challenges & Growth Areas

1. **Story grounding was repeatedly wrong on platform specifics** *(recurring — was Epic 8 retro's #1 risk)*. 7.2's AC implied i18n lived in `[locale]` (real boundary is the root not-found); 7.3's AC2 said "register the SW via a `next.config.ts` plugin" — but Next 16 is Turbopack-default, so the webpack `@serwist/next` plugin **would not run**, forcing a pivot to `@serwist/turbopack` + a route handler + a `createContext` client-boundary workaround. A literal implementation of the story would have failed.
2. **ACs pinned to external tool versions drifted out from under us.** AC5 "Lighthouse PWA ≥ 90" was **obsolete** — Lighthouse 12.6.1 removed the PWA category. Reconciled to a maintainer-approved installability checklist, but the AC measured a thing the tool no longer reports.
3. **A new gate surfaced pre-existing debt → the a11y suite is RED at HEAD.** 7.3's new mobile-axe project (correctly built per Epic 8 A7) immediately exposed pre-existing WCAG 1.4.3 contrast debt (venue-card amber labels ≈1.63:1, About/Privacy footer ≈3.13:1). The team correctly refused to scope-creep it and `test.fixme`'d it honestly toward Story 5.1 — but **the Playwright a11y gate now genuinely fails at HEAD**, and the canonical `story-review.sh` gate doesn't run Playwright e2e, so the failure is invisible to the green story gate.
4. **Placeholder PWA assets shipped.** Token-derived placeholder icons (no source brand mark exists) — acceptable for the build, but a real install-quality launch needs a real mark.
