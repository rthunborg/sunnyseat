## Dev Notes

### Architecture Alignment

This story establishes the foundational Next.js infrastructure for the platform migration from .NET 8/Azure to Next.js/Vercel/Supabase. This is the first story in Epic 6 and sets up the development environment that all subsequent stories will build upon.

### Previous Epic Dependencies

No previous epic dependencies - this is the foundation story for Epic 6.

### Technical Implementation

**Next.js Architecture:**

- Next.js 14+ with App Router (not Pages Router)
- TypeScript (strict mode)
- Server Components for data fetching
- Client Components for interactivity
- API Routes for backend endpoints
- Server Actions for form submissions

**Project Structure (created in Task 1):**

```
/app                    # Next.js App Router (Task 1)
  /api                  # API routes (created in Story 6.4)
  /(routes)             # App Router pages (created in Story 6.6)
/lib                    # Shared libraries (Task 1)
  /supabase             # Supabase client (Task 5)
    /client.ts          # Client-side Supabase client (anon key)
    /server.ts          # Server-side Supabase client (service role)
  /services             # Business logic (created in later stories)
  /utils                # Utility functions (Task 1)
/components             # React components (Task 1)
  /server               # Server Components (created in Story 6.6)
  /client               # Client Components (created in Story 6.6)
/public                 # Static assets (Task 1)
```

**Supabase Setup (Task 5):**

- Client-side client: `/lib/supabase/client.ts` - uses `NEXT_PUBLIC_SUPABASE_ANON_KEY` for browser/client components
- Server-side client: `/lib/supabase/server.ts` - uses `SUPABASE_SERVICE_ROLE_KEY` for API routes and server components
- TypeScript types: Generate Supabase types for database schema
- Environment variables: Managed via `.env.local` (see Environment Configuration below)

**Tailwind CSS (Task 3):**

- Source config: `src/frontend/public/tailwind.config.js`
- Custom colors to migrate: `primary: '#0EA5E9'`, `sunny: '#22C55E'`, `partial: '#F59E0B'`, `shaded: '#9CA3AF'`
- Custom fontSize: `headline`, `body`, `caption` with line heights
- Custom borderRadius: `16px` default
- Content paths: `['./app/**/*', './components/**/*', './lib/**/*']`

### Environment Configuration

**Required Environment Variables (`.env.local`):**

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://[project].supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=[anon-key]
SUPABASE_SERVICE_ROLE_KEY=[service-role-key]

# External APIs (for future stories)
WEATHER_API_KEY=[openweathermap-key]
WEATHER_API_URL=https://api.openweathermap.org/data/2.5

# Application
NODE_ENV=development
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

**Note:** Create `.env.example` with these variables (without values) for documentation.
