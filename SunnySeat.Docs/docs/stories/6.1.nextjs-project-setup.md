# Story 6.1: Next.js Project Setup & Configuration

## Status

✅ **ready-for-dev**

## Story

**As a** development team,  
**I want** a complete Next.js foundation with proper tooling and Supabase integration,  
**so that** we can begin migrating SunnySeat features to the modern Next.js platform with a solid, scalable infrastructure.

## Acceptance Criteria

1. Next.js application runs locally on `npm run dev` ?
2. TypeScript compilation succeeds with no errors ?
3. Tailwind CSS styles are applied correctly ?
4. ESLint and Prettier are configured and working ?
5. Supabase client can connect to Supabase project ?
6. Environment variables are loaded from `.env.local` ?
7. Build process completes successfully (`npm run build`) ?
8. Project structure follows Next.js App Router conventions ?

## Dev Notes

### Architecture Alignment

This story establishes the foundational Next.js infrastructure for the platform migration from .NET 8/Azure to Next.js/Vercel/Supabase. This is the first story in Epic 6 and sets up the development environment that all subsequent stories will build upon.

### Previous Epic Dependencies

No previous epic dependencies - this is the foundation story for Epic 6.

### Technical Implementation

**Next.js Architecture:**

- Next.js 14+ with App Router (not Pages Router)
- TypeScript (strict mode)
- Server Components for data fetching
- Client Components for interactivity
- API Routes for backend endpoints
- Server Actions for form submissions

**Project Structure:**

```
/app
  /api              # API routes
  /(routes)         # App Router pages
/lib
  /supabase         # Supabase client
  /services         # Business logic
  /utils            # Utility functions
/components         # React components
  /server           # Server Components
  /client           # Client Components
/public             # Static assets
```

**Supabase Setup:**

- Supabase client library integration
- Environment variable management via `.env.local`
- Connection configuration for Supabase project

**Tailwind CSS:**

- Migrate existing Tailwind configuration from current frontend
- Maintain existing design system and styles

### Environment Configuration

**Development Environment Variables:**

- `NEXT_PUBLIC_SUPABASE_URL` - Supabase project URL
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` - Supabase anonymous key
- `SUPABASE_SERVICE_ROLE_KEY` - Supabase service role key (server-side only)
