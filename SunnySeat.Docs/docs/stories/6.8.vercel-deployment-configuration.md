### Environment Variables

**Required Environment Variables (from Story 6.1 + additional):**

- `NEXT_PUBLIC_SUPABASE_URL` - Supabase project URL
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` - Supabase anonymous key
- `SUPABASE_SERVICE_ROLE_KEY` - Supabase service role key (server-side only)
- `WEATHER_API_KEY` - OpenWeatherMap API key (from current `appsettings.json`)
- `WEATHER_API_URL` - OpenWeatherMap API URL (default: `https://api.openweathermap.org/data/2.5`)
- `NEXT_PUBLIC_APP_URL` - Application URL (for production: `https://sunnyseat.se`)
- `NODE_ENV` - Environment (development/preview/production)
