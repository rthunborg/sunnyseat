### Migration Approach

**Entity Framework to Supabase:**

- Convert LINQ queries to Supabase client calls
- Convert Entity Framework models to Supabase queries
- Handle async operations properly

**Example Conversion (from `PatioEndpoints.cs`):**

```typescript
// Entity Framework (old) - from IPatioRepository
var patios = await patioRepository.GetPatiosNearPointAsync(
  searchPoint,
  radius,
  cancellationToken
);

// Supabase (new) - using RPC for spatial queries
const { data: patios } = await supabase.rpc("get_patios_near_point", {
  search_lat: latitude,
  search_lng: longitude,
  radius_meters: radius * 1000, // Convert km to meters
});

// Or direct query for simple filters
const { data: patios } = await supabase
  .from("patios")
  .select("*")
  .eq("venue_id", venueId);
```

**Note:** Complex spatial queries should use Postgres RPC functions (created in Story 6.5) rather than direct Supabase queries.
